# Агент: ежедневный мониторинг практики по ст. 61.2 Закона о банкротстве

Агент каждое утро ищет новую судебную практику по статье 61.2 Федерального закона от 26.10.2002 № 127-ФЗ «О несостоятельности (банкротстве)» (оспаривание подозрительных сделок должника), анализирует её и присылает сводку на **legalagenc@yandex.ru**.

## Как устроено

| Параметр | Значение |
|---|---|
| Механизм | Routine (запуск по расписанию) Claude Code, `trig_01RrVQYPPu928YqVsdks3kyg` |
| Расписание | ежедневно в **05:50 МСК** (`CRON_TZ=Europe/Moscow 50 5 * * *`); на поиск и анализ уходит 10–20 минут, поэтому сводка готова примерно к 6:00 |
| Где выполняется | в той сессии Claude Code, где агент был настроен. У неё подключены Gmail и Legal Data Hunter |
| Отправитель | Gmail-аккаунт, подключённый к Claude (01psb.mosreg@gmail.com) |
| Получатель | legalagenc@yandex.ru |
| Инструкция агента | [`agent/routine-prompt.md`](agent/routine-prompt.md) — копия текста, сохранённого в расписании |

**Не архивируйте и не удаляйте сессию, в которой настроен агент.** Расписание запускает агента именно в ней. Если сессию удалить, запуски прекратятся.

## Что агент делает при каждом запуске

1. Определяет период: от даты последней сводки до сегодня. Номера уже разобранных дел берёт из раздела «Реестр» прошлых писем в Gmail, чтобы не повторяться.
2. Делает не меньше 12 поисковых запросов по уровням значимости:
   - **A** — определения СКЭС ВС РФ, обзоры Президиума ВС РФ, постановления Пленума, акты КС РФ, изменения закона;
   - **B** — постановления арбитражных судов округов, в первую очередь АС Московского округа;
   - **C** — нижестоящие суды, только резонансные дела.
3. По каждому акту составляет:
   - реквизиты;
   - фабулу;
   - правовую позицию со ссылками на нормы;
   - оценку новизны;
   - практическое применение для заявителя и для ответчика;
   - готовую формулировку для заявления или отзыва.
4. Отмечает, насколько проверен акт: ✅ — текст сверен с первоисточником; ⚠️ — акт известен только по вторичной публикации, перед использованием его нужно сверить на kad.arbitr.ru / vsrf.ru.
5. Отправляет одно HTML-письмо с темой «Практика по ст. 61.2 Закона о банкротстве — сводка на ДД.ММ.ГГГГ». Если нового нет, отправляет короткое письмо с пометкой «новых актов не выявлено».

Главное правило агента — не выдумывать номера дел, даты и цитаты. Акт попадает в сводку, только если у него есть ссылка на источник. Кавычки ставятся только для дословного текста.

## Источники и текущие ограничения

- **Веб-поиск** работает. Это основной источник свежих актов и публикаций: vsrf.ru, consultant.ru, garant.ru, pravo.ru, zakon.ru, rapsinews.ru, probankrotstvo.ru и другие.
- **Legal Data Hunter** (архив sudact.ru с полными текстами) нужен для сверки текста акта. Он отстаёт примерно на два месяца, поэтому новые акты в нём не ищут.
- **Прямое открытие сайтов** (kad.arbitr.ru, vsrf.ru, sudact.ru, consultant.ru, garant.ru и др.) сейчас **закрыто сетевой политикой облачного окружения**. Поэтому часть актов получит статус ⚠️.

Чтобы агент мог открывать полные тексты, расширьте сетевой доступ окружения: меню облачного окружения в заголовке сессии → **Edit** → **Network access**. Там выберите более широкий уровень доступа или добавьте домены:

```
vsrf.ru, www.vsrf.ru, kad.arbitr.ru, *.arbitr.ru, sudact.ru, www.consultant.ru,
www.garant.ru, base.garant.ru, pravo.ru, zakon.ru, rapsinews.ru, probankrotstvo.ru,
fedresurs.ru, bankrot.fedresurs.ru, publication.pravo.gov.ru, ksrf.ru
```

Уровни доступа описаны здесь: https://code.claude.com/docs/en/claude-code-on-the-web

Картотека kad.arbitr.ru защищена от автоматических запросов. Даже при открытом доступе агент не всегда сможет открыть её страницы, поэтому реквизиты ключевых актов сверяйте в ней вручную.

## Как изменить

Все изменения можно попросить сделать прямо в сессии, где настроен агент. Примеры:

- время запуска: «запускай в 7:00» (расписание обновится);
- получатели: «добавь копию на …»;
- тематика: «добавь ст. 61.3 и субсидиарную ответственность»;
- приостановка: «приостанови агента» (расписание будет выключено, но сохранится);
- внеплановый запуск: «запусти сводку сейчас».

После изменения инструкции обновите и файл `agent/routine-prompt.md`, чтобы копия совпадала с текстом в расписании.
